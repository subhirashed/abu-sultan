### 🟡 جاهز وينتظر موافقتك
1. **خطة الـ $20:** Craigslist $5 + إعلان فيسبوك واتساب $10 + احتياطي $5.
2. **نشر إعلان Craigslist** (الزاوية 1) في منطقة واحدة (الافتراضي: Broward).
3. **رسائل الشراكات** لمخازن التخزين ومكاتب التأجير.

### 🔴 محجوب – يحتاج حسابك أو قرارك
- **قرار قانوني (الأهم):** قانون فلوريدا 507 يعرّف "mover" بمن يحمّل **أو** يفرّغ أغراض منزلية مقابل أجر، ولا يوجد إعفاء صريح للعمالة فقط. الغرامة حتى $5,000. الخيارات: اتصل بـ FDACS على 1-800-435-7352 (10 دقائق)، أو ابدأ بإعلان الزاوية 3 (أثاث/تخزين) حتى تتأكد، أو سجّل (~$300 + تأمين). راجع `01-research` §6.
- **معلومات ناقصة:** الرمز البريدي لمقرّك (يحدد منطقة Craigslist ونطاق الإعلان)، هل تملك شاحنة، هل يتوفر مساعد ثانٍ.
- **تسجيل الدخول للحسابات:** Craigslist، صفحة فيسبوك + Ads Manager (وسيلة دفع)، WhatsApp Business، Nextdoor، U-Haul Moving Help، استضافة صفحة الهبوط (GitHub Pages أو Netlify).
- **لا يوجد تكامل واتساب/SMS** في هذه الجلسة: الروابط جاهزة والرسائل تصل لهاتفك مباشرة، لكنني لا أقرأ ولا أرسل رسائل.
